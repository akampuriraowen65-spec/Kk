# OwiTok

A phone-friendly TikTok-style prototype.

Files:
- index.html
- style.css
- script.js
- .github/workflows/deploy.yml

Important:
Browser security means locally selected phone videos are stored as temporary object URLs. They work while the page/session remains available, but this prototype does not upload videos to a server. A real multi-user app needs a backend/database/storage service.

Video audio is supported. Videos start muted for browser autoplay compatibility; tap the speaker button to enable sound. Double-tap the video to like.
